YouTube stream key कहाँ मिलेगी

youtube stream key kahan milega: फ़ोन के browser और computer पर YouTube Studio से key copy करने के steps, और दो आम गलतियाँ।

Read in English

AFK Live आपका stream YouTube पर एक stream key से भेजता है: abcd-1234-efgh-5678-ijkl जैसा एक code, जिससे YouTube समझता है कि वीडियो किस चैनल का है। आप इसे YouTube से एक बार copy करके AFK Live में paste करते हैं। Google से sign in की ज़रूरत नहीं।

फ़ोन पर key copy करें

  1. YouTube Studio app में stream key नहीं दिखती। फ़ोन के browser (जैसे Chrome) में studio.youtube.com खोलें और उसी चैनल से sign in करें।
  2. Browser के menu (⋮) में Desktop site चालू करें। पेज छोटा दिखेगा; zoom करके पढ़ें।
  3. ऊपर Create → Go live दबाएँ। YouTube live streaming चालू करने को कहे तो चालू करें। पहली बार इसमें 24 घंटे तक लग सकते हैं।
  4. बाएँ menu में Stream चुनें (Webcam या Manage नहीं)।
  5. Stream settings में Stream key के पास Copy दबाएँ।
  6. AFK Live में key को YouTube stream key वाले खाने में paste करके save करें (setup में, या Destinations → Add a destination → YouTube)। हम उसी समय एक छोटी test picture भेजकर key जाँच लेते हैं।

Computer पर

  1. YouTube Studio का live dashboard खोलें और सही चैनल से sign in करें।
  2. बाएँ menu में Stream चुनें।
  3. Stream settings में Default stream key चुना रहने दें और Copy दबाएँ।
  4. AFK Live में paste करके save करें।

Default key और scheduled live की key

Default stream key हर live के लिए वही रहती है, इसलिए 24/7 stream के लिए यही रखें। YouTube Studio के Manage tab में schedule किए गए live की अपनी अलग key हो सकती है; वो key डालेंगे तो stream उसी scheduled live में जाएगा। जब तक आप यही न चाहें, Stream tab की default key ही copy करें।

आम गलतियाँ

  • Key की जगह Stream URL paste करना। Key के ठीक ऊपर Stream URL (rtmp://a.rtmp.youtube.com/live2) दिखता है। AFK Live को वो पहले से पता है; सिर्फ़ key paste करें।
  • गलत चैनल। एक से ज़्यादा चैनल हैं, तो copy करने से पहले YouTube Studio में ऊपर दाईं ओर की फ़ोटो देख लें।

Key किसी को न दें

जिसके पास आपकी key है, वो आपके चैनल पर stream कर सकता है। इसे WhatsApp group या screenshot में भी share न करें। AFK Live key को encrypted रखता है और सिर्फ़ आख़िरी चार अक्षर दिखाता है। अगर किसी और ने देख ली हो, तो YouTube Studio में नई key बनाएँ (Stream key menu → Create new stream key) और AFK Live में नई key paste करें।

अक्सर पूछे जाने वाले सवाल

क्या stream key हर live के लिए बदलनी पड़ती है?

नहीं। Default stream key हर live के लिए वही रहती है, इसलिए AFK Live में एक बार डाल दी तो बार-बार copy नहीं करनी पड़ती। Key तभी बदलें जब किसी और ने उसे देख लिया हो।

Key डाल दी, फिर भी YouTube पर कुछ नहीं दिख रहा?

YouTube Studio में Auto-start चालू करें, और देखें कि key scheduled live की तो नहीं। पूरी checklist: AFK Live पर live, YouTube पर नहीं (अंग्रेज़ी में)।
