# Fonts

`Poppins-Medium.ttf`: Poppins, Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins).
Licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). Used by the stream
studio to draw text overlays; bundled so every worker renders text the same way. It covers Latin and
Devanagari.

`NotoSans<Script>-Medium.ttf` (Bengali, Devanagari, Gujarati, Gurmukhi, Kannada, Malayalam, Tamil, Telugu)
and `NotoSansOriya-Regular.ttf` (Odia has no Medium cut): Noto Sans, Copyright 2022 The Noto Project
Authors (https://github.com/notofonts). Licensed under the SIL Open Font License, Version 1.1; the full
text is in `OFL-Noto.txt`. Unmodified, from notofonts.github.io (hinted TTF). GR-8: overlay text in
these scripts falls back to them (`OverlayFonts`), so creators can write in their own language. The OFL
allows bundling them with software, free of charge, as long as the fonts aren't sold on their own.
